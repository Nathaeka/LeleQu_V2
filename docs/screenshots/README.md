# Panduan Pengambilan Screenshot (`docs/screenshots/`)

Silakan ambil tangkapan layar (screenshot) langsung dari VS Code dan browser saat menjalankan aplikasi, lalu simpan ke folder ini dengan nama file berikut:

1. `01-project-structure.png` — Struktur folder repository (`src/` frontend dan `backend/` NestJS) di Explorer VS Code.
2. `02-nest-resource.png` — Output CLI `nest g resource products` dan struktur folder `backend/src/products/`.
3. `03-product-entity.png` — Kode `backend/src/products/entities/product.entity.ts`.
4. `04-crud-service.png` — Kode implementasi CRUD in-memory & exception di `backend/src/products/products.service.ts`.
5. `05-controller-endpoints.png` — Kode endpoint REST API di `backend/src/products/products.controller.ts`.
6. `06-dto-validation.png` — Kode validasi `CreateProductDto` dan `UpdateProductDto`.
7. `07-global-validation-pipe.png` — Kode `ValidationPipe` global dan CORS di `backend/src/main.ts`.
8. `08-get-products.png` — Hasil pengujian `GET /products` dan `GET /products/:id` di REST Client (`products.http`).
9. `09-post-products.png` — Hasil pengujian `POST /products` dan uji validasi error `400` di REST Client.
10. `10-patch-products.png` — Hasil pengujian `PATCH /products/:id` di REST Client.
11. `11-delete-products.png` — Hasil pengujian `DELETE /products/:id` dan uji `404 Not Found` di REST Client.
12. `12-frontend-integration.png` — Tampilan halaman Katalog Produk / Admin CMS LeleQu di browser yang terhubung ke API NestJS.
